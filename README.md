# CarCare 

CarCare is a mobile vehicle maintenance management app that helps users track their vehicles, service history, and upcoming maintenance. The app uses the **NHTSA API** to retrieve vehicle information and **Firebase** for authentication, database storage, and image uploads.

---

## Features

###  Authentication
- User registration and login
- Persistent sessions
- Secure account management

###  Vehicle Management
- Add and manage vehicles
- View vehicle details
- Retrieve vehicle data using the NHTSA API

###  Maintenance Tracking
- Add service records
- Track:
  - Service type
  - Date
  - Mileage
  - Notes
- View and delete maintenance history
- Real-time updates using Firestore

###  Profile
- View profile information
- Update password
- Change profile picture
